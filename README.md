# Ekuru Shadrach — simple two-page site

This workspace contains a minimal two-page static site (HTML/CSS/JS).

Files added/edited:
- `index.html` — introduction / home page
- `courses.html` — list of courses
- `index.css` — styles (blue & white palette, subtle animations)
